Virtual Hospital Project at UCLouvain/EPL

The project aims to develop educational tools in medical informatics, specifically a virtual hospital, to support the teaching of engineering and computer science students. This virtual platform will simulate real hospital IT systems, allowing students to interact with it on their laptops before entering the workforce. The platform will integrate open-source software and datasets into a virtual machine, providing students with a learning environment for hospital IT systems, software integration, healthcare database development, as well as performing statistical analysis, image processing, AI training, data exchange (HL7/FHIR) simulator, and AI model integration into this platform. This is primarily an initiative in medical informatics education, which is why it is supported by EPL.

Virtual Hospital Platform

The virtual Hospital Platform is part of the Virtual Hospital project, which includes an open source hospital information system, an e-health system, and various health-related tools. Hospitals often lack the staff needed to develop these technologies, which limits the opportunities for engineers and computer scientists to gain hands-on experience. As a result, these professionals typically learn about clinical technologies—such as patient databases, bioanalysis, imaging systems, healthcare networks, medical billing, and standardization of medical terminology—only after being hired into the healthcare sector. The platform aims to fill this gap by offering internships to engineers and computer scientists in the healthcare sector. It combines theoretical training with practical experience using realistic systems and representative medical data.

Architecture

The Virtual Hospital Platform is a key part of the Virtual Hospital Project, which provides open source hospital information systems, e-health tools and other medical technologies. It provides hands-on training using real systems and medical data to enhance learning.

Core components of our platform

  • GNU Health HIS(Hospital Information System)
  • Ozone EHR(Electronic Health Record)
  • OpenEHR(Open Electronic Health Record)
  • PARROT(AI-based Imaging Processing Platform)
  • OpenTPS(Treatment Planning System)
  • Mirth Connect(Integration Engine)
  • Jupyter (Interactive Computing Environment)
  • HAPI FHIR(Healthcare API for FHIR)
  • Senaite(Enterprise Open Source Laboratory System)
