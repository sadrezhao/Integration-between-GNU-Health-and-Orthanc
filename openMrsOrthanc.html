Connecting Orthanc and OpenMRS

The aim of this project is to provide a seamless integration between OpenMRS and an Orthanc PACS system, enabling the processing of medical imaging data in DICOM format. With this connection, OpenMRS will use the Stone and OHIF DICOM viewers to visualise patient image data. The connection leverages the OpenMRS FHIR server, as well as Orthanc's FHIR resources, ensuring robust compatibility. The implementation follows the IHE standard, ensuring compliance with industry best practices.

Radiology Module

We are planning to develop this project to create a new radiology module within the OpenMRS electronic healthcare system. This module aims to streamline the management of imaging data and support key workflows in radiology departments. key workflows in radiology departments. Key features of this module include:

  • FHIR ImagingStudy Resource integration: Implement the FHIR ImagingStudy resource to standardise and expose imaging data via OpenMRS' FHIR server, ensuring interoperability and compliance with healthcare standards.
  • PACS connectivity: Enable seamless integration with Orthanc PACS through the configuration support for both local and remote connections, facilitating access to imaging systems.
  • Visualisation of patient image data: View patient image data using Orthanc's DICOM viewers, providing an interface for image preview.
  • Worklist Management in OpenMRS: manage worklist directly within OpenMRS, improving workflow efficiency and coordination across healthcare teams.

This initiative is designed to improve the efficiency of radiology operations and provide healthcare providers with tools to manage imaging data. Stay tuned for updates as we develop this critical functionality!
